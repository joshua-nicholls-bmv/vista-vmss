# Third-party components

- Microsoft .NET desktop runtime: distributed with the portable package under its applicable Microsoft/.NET terms. https://github.com/dotnet/runtime/blob/main/LICENSE.TXT
- Microsoft Flight Simulator SimConnect libraries: Microsoft components; their SDK/runtime terms remain applicable. They are required for simulator connectivity.
- OpenStreetMap map tiles/data: attribution is shown in the application. https://www.openstreetmap.org/copyright
- SimBrief and Navigraph: external services, not affiliated with this project; their account/service terms apply.

No Effra font files are bundled. The application uses an installed Effra font when available and falls back to Segoe UI. Portable briefing PDFs use standard PDF fonts.
